PORTFOLIO PROJECT 02

不安を減らし、
最初の一歩につなげる。

架空のパーソナルジム「HABIT ROOM」のWebサイト。店舗サイトに必要な情報の分かりやすさと、ブランドの空気感を両立する制作サンプルです。

実在の店舗ではありません。店舗・スタッフ・料金・サービスはすべて架空です。予約・決済・問い合わせの送信は行いません。

課題と目指した体験

運動を始めたいけれど、体力・料金・続け方が分からない。そんな初心者を想定し、勢いだけで予約へ誘導するのではなく、内容と条件を確認してから一歩を踏み出せる構成にしました。

情報設計とデザイン

トップページでは「考え方 → 自分に合う運動 → 空間 → 不安の解消」の順に紹介。プログラムと料金を独立したページに分け、判断に必要な情報へ直接アクセスできるようにしました。

アイボリーと黒を軸に、ライムは主に操作の目印として使っています。写真と大きな見出し、罫線で区切る文章を組み合わせ、同じカードの繰り返しにならないレイアウトにしました。スマートフォンでは写真の見せ方と文章の順序を保ちながら1列に切り替えます。

予約体験を、安全に試す

実際のサーバーを持たず、入力・検証・確認・デモ終了までをページ内で行います。日付の範囲や月曜定休というサンプル条件を検証し、修正時には入力を維持。終了時は内容を破棄します。情報を送信・保存する処理や解析サービスはありません。

技術と品質

Astro・TypeScript・CSSによる静的サイトです。通常ページのJavaScriptはメニュー操作だけに絞り、写真はビルド時にWebPへ最適化。画面幅に応じた画像を配信し、下部画像は遅延読み込みにしています。

見出し構造、スキップリンク、フォーカス表示、ネイティブの質問アコーディオンを採用。動きを減らす設定ではスクロールや遷移の演出を抑えます。ページごとのメタ情報、OG画像、サイトマップを用意し、架空住所やレビューの構造化データは付けていません。

検証ではChromium・Firefox・WebKit、320 / 393 / 768 / 1280px、文字200%表示を対象にしています。自動検査で分かることと、実機で確かめる必要があることを分け、具体的な結果は同梱の品質レポートに記録しています。

写真と制作ツール

写真はPexelsのライセンスを確認した素材を使用。写っている人物や施設はこの架空店舗とは関係がありません。人物をスタッフとして紹介せず、スタッフ紹介は指導方針を伝える役割設定にしています。

制作ではCodexを活用して設計・文章・実装・自動検証を進めました。今回の改善では、最初の画面で運動の内容と通い方が伝わるよう情報を整理し、ルート配信とサブディレクトリ配信の両方を検証できるようにしています。架空の顧客実績や第三者の評価は掲載していません。

完成した範囲と、公開前の課題

6ページとこの紹介ページ、ブラウザ内予約デモを実装しています。実予約システムや店舗運営の検証は対象外です。公開URLと配信パスを設定してビルドすると、canonical・OG・サイトマップをまとめて生成します。URL未設定の公開ビルドは停止する仕組みです。実iPhone・Androidでの操作感や、当事者による読み上げ確認も今後の検証項目です。
