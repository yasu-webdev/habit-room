PROGRAMS

今の自分から、始める。

いきなり高い目標を決めなくても大丈夫。目的と体調、生活のリズムに合わせて、3つのプログラムから選ぶ設定です。

START
GENTLY.

はじめての運動 / 50分

はじめる、を整える。

「正しく動けているかな？」を、一緒に確かめる時間。呼吸や姿勢を確認しながら、自分の体重を使ったやさしい動きから始めます。

こんな方に
運動経験が少ない方、久しぶりに体を動かす方
内容の例
対話・ウォームアップ → 基本の動き → 振り返り
目指すこと
日常の中で取り入れやすい動きを見つける。

BUILD YOUR
BASE.

ベーシック筋力 / 50分

動ける土台をつくる。

重さや回数を競うのではなく、今の自分に合う負荷を。スクワットやプッシュなどの基本動作を中心に、全身をバランスよく動かします。

こんな方に
基本から筋力トレーニングを学びたい方
内容の例
動きの確認 → 自重・ダンベル運動 → クールダウン
目指すこと
基本のフォームと、自分に合う負荷の感覚を学ぶ。

MOVE WITH
EASE.

モビリティ / 50分

心地よく、ほぐす。

座る時間が長い日も、忙しく過ごした日も。呼吸に合わせて関節をゆっくり動かし、自分の体の感覚に目を向けます。

こんな方に
ゆったりした運動から始めたい方
内容の例
呼吸 → 関節を動かすエクササイズ → ストレッチ
目指すこと
気持ちよく動ける範囲を知り、運動のきっかけにする。

FIRST SESSION

体験は、話すことから。

  1. ヒアリング / 約15分

    運動経験、生活のリズム、気になることを伺います。

  2. トレーニング / 約30分

    体調や動きを確認し、無理のないメニューを試します。

  3. 振り返り / 約15分

    感想を話し、続け方や自宅での小さな習慣を考えます。
